Проект для обнаружения аномалий в временных рядах температуры масла `OT` на основе набора данных ETTm1. В скрипте сравниваются три метода:

- Isolation Forest
- One-Class SVM
- Autoencoder (MLPRegressor)

Решение оценивает, как каждый алгоритм выделяет аномальные точки после временного разбиения данных на обучающий и тестовый наборы, а также визуализирует результаты в виде графиков.

## Что делает проект

- Загружает Dataset работы  Трёхфазного масляного силового трансформатора 40 МВА ETTm1 с GitHub
- Выбирает признаки `HUFL`, `HULL`, `MUFL`, `MULL`, `LUFL`, `LULL`, `OT`
- Делит данные по времени: 70% обучающая часть, 30% тестовая
- Заполняет пропуски медианой из обучающего набора
- Нормализует признаки через `StandardScaler`
- Обучает три модели аномалий:
  - `IsolationForest`
  - `OneClassSVM`
  - автоэнкодер на основе `MLPRegressor`
- Сравнивает результаты по количеству найденных аномалий, доле аномалий и времени работы
- Строит графики пересечений срабатываний методов и ошибки восстановления автоэнкодера

## Требования

Перед запуском убедитесь, что установлены:

- Python 3.9+
- pip

Зависимости:

```bash
pip install numpy pandas matplotlib scikit-learn
```

## Запуск

В корне проекта выполните:

```bash
python main.py
```

После запуска скрипт:

1. загрузит данные из удалённого источника;
2. выведет информацию о пропусках и сдвиге средних значений;
3. рассчитает метрики для каждого метода;
4. отобразит таблицу сравнения моделей;
5. покажет графики с найденными аномалиями.

## Пример вывода

В консоли будут напечатаны:

- число пропусков;
- смещение средних значений тестового набора относительно обучающего;
- сводка по количеству аномалий для каждого метода;
- пересечения срабатываний между методами;
- сравнительный отчёт по доле аномалий.

Также будут открыты графики:

- `Isolation Forest` vs `One-Class SVM` vs `Autoencoder`
- моменты срабатывания методов
- ошибка восстановления автоэнкодера и выбранный порог

## Методология

Проект использует классический подход обнаружения аномалий в временных рядах:

- обучение на нормализованных признаках;
- разбиение данных по времени, чтобы избежать утечки данных между обучением и проверкой;
- сравнение результатов на одном и том же тестовом наборе;
- оценка пересечения срабатываний между моделями для выявления устойчивых аномалий.

## Примечания

- Скрипт использует внешний набор данных ETTm1, поэтому при отсутствии интернет-соединения загрузка может завершиться с ошибкой.
- Параметры, такие как `CONTAMINATION`, `FIT_SAMPLE_SIZE` и `SEED`, находятся в начале файла и могут быть изменены под конкретную задачу.
- Графики сохраняются в текущую директорию как изображения при необходимости, если это настроено в среде запуска.
